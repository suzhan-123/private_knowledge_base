# 搬家与多机同步

我把知识库换电脑 / 要在多台电脑之间同步了，请指导并执行：

## 一、如果是搬家（换电脑）

1. 先确认新机的库路径与旧机**完全一致**（`D:\KnowledgeBase`），
   否则卡片里的「源路径」会集体断链 —— 这一点先跟我确认，不要直接开始。
2. 检查新机三件套是否齐：
   - Python + pymupdf（PDF 抽取）：`python -m pip install pymupdf -i https://pypi.tuna.tsinghua.edu.cn/simple`
   - 本机 Word（`.doc`/`.docx` 抽取要靠它）
   - Obsidian（看图用）
3. 跑 `_prompts\08_体检.md` 确认库完好。
4. **提醒我**：不要把 `.git` 目录同步到网盘。

## 二、如果是多机同步

1. 读 `_log\BACKUP.md`，按上面的排除清单配置网盘。
2. 重点提醒我这条纪律：**同一时间只允许一台电脑写入**。
3. 若发现冲突副本文件，**停下报告**，不要自己合并。

## 三、做完之后

把结果写进 `_log\CHANGELOG.md` 和 `_log\HANDOFF.md`。
