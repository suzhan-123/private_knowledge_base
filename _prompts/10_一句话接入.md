# 一句话接入（四个 agent 通用）

## 怎么用

打开你要用的 agent，把下面这段**整段粘进去**，它就会接管这个知识库。

---

## 通用开场白（四家都能用，复制这一段）

```
你是我的私人知识库管理员。请先读 D:\KnowledgeBase\AGENTS.md，
然后严格按它的规则为我工作，不要自行开工，先告诉我你理解的当前状态。

我的需求是：<在这里写你要做什么>
```

---

## 分家说明

| Agent | 会不会自动读规则 | 你要做什么 |
|---|---|---|
| **harness（DSH）** | ✅ 工作目录设成 `D:\KnowledgeBase` 就自动读 `AGENTS.md` | 直接说需求 |
| **Codex** | ✅ 同上 | 直接说需求 |
| **Claude Code** | ✅ 读同目录的 `CLAUDE.md`（库里已建，内容就是指向 AGENTS.md） | 直接说需求 |
| **Kimi Code CLI** | ❌ **不会**（官方"自动加载 AGENTS.md"仍在排期，见 MoonshotAI/kimi-cli issue #850） | **必须先粘上面的开场白** |

> **共同前提**：agent 只在自己「当前打开的目录」里找规则文件。
> 如果它不是在 `D:\KnowledgeBase` 里启动的，就必须用开场白把路径告诉它。

---

## 常用需求怎么说（照抄即可）

| 你想干什么 | 就这么说 |
|---|---|
| 归档新文件 | 我往 `00_收件箱\待归档\` 放了几个文件，帮我归档 |
| 找参照本子 | 我要写 XX 方向的青年基金，库里哪些本子能当参照（先读卡片，别整篇读原文） |
| 查创新点撞车 | 我这个创新点是「XXX」，库里有没有做过类似的 |
| 写本子 | 按 `_prompts\06_写本子.md` 的流程帮我搭立项依据的骨架 |
| 体检 | 按 `_prompts\08_体检.md` 跑一次体检 |
| 找论文弹药 | 我要在立项依据里论证「XXX」，库里 `45_论文` 有哪些论文能支撑 |

---

## 每一步它都会先给你计划

按库规则，agent 做任何写入前都会先发计划等你批准。批准口令：

- 「**批准**」= 全部照做
- 「**批准到第 N 步**」= 只做前 N 步
- 「**修改：…**」= 改完计划重发
