# 我的私人知识库

## 这是什么
一个放在 D:\KnowledgeBase 的私人资料库。全部是普通文件和文字：
没有数据库、没有需要注册的账号、不依赖任何一家公司的服务。
任何 AI（Codex / Claude / Kimi / 本机 harness）都能直接读，不会被某个软件锁住。

## 我平时只做三件事
1. 把新资料丢进 `00_收件箱\待归档\`
2. 把提示词复制给 AI，回一句「批准」
3. 抽查它做出来的卡片，说「可以，继续」

**我不需要敲任何命令。**

## 目录说明
- `00_收件箱\`   新资料放这里；`需人工确认\` 放抽不出来的；`重复文件\` 放指纹撞车的
- `10_基金本子\` 国自然标书：raw 原件 / md 文字 / cards 卡片 / 专题
- `20_教学\`、`30_办公\`、`40_文献\`（综述/标准/专利/教材）、`45_论文\`（学术论文）  同样的结构
- `50_模板库\`   技术路线图模板、申报指南、题目统计、写作经验、自检清单
- `60_使用手册\` **使用说明书（不懂技术也能看）**：上手、Obsidian、加文件、写本子、备份、常见问题
- `_schema\`     规则：卡片字段、标签表、命名规范、评分标准
- `_prompts\`    各种场景的提示词，直接复制给 AI 用
- `_tools\`      抽取工具（Python + 本机 Word）
- `_stage0\`     筛选清单与报告
- `_log\`        变更日志与交接单

## 找资料
- 自己看：用文件资源管理器搜索，或让 AI 报给你
- 让 AI 找：说「按 _prompts\04_找参照.md 执行，主题是 XXX」

## 备份与换电脑
- 把整个 `D:\KnowledgeBase` 文件夹复制走即可，**不需要任何服务器**
- 原件备份（raw/）另外放网盘或移动硬盘
- 如果用了网盘同步：**不要把 .git 目录同步上去**（会损坏仓库）
- 新电脑：装 Python + 一个 AI 工具，然后让 AI 跑一次 `_prompts\01_接入自检.md`

## 为什么这样设计
1. 全部用普通文本文件 -> 任何 AI 都能读，换工具不丢东西
2. 一张卡片压缩一篇本子 -> AI 不用读 8000 字原文就能了解写作范式，省时间省钱
3. 机械活（抽取/改名/编号）交给脚本 -> 不花 AI 的钱；只有"读懂并提炼"才交给 AI
