# 术语表

> 手册和 AI 回复里出现的词，都在这里。按拼音/字母大致排序。

---

## 关于文件

| 词 | 大白话解释 |
|---|---|
| **raw** | 各分类下存**原件**的文件夹（PDF/Word/PPT）。**只读，永远别动** |
| **md** | 存**抽取出来的文字**的文件夹。AI 读这个，你不用管 |
| **cards** | 存**卡片**的文件夹。**你主要看这个** |
| **原件** | 你最初放进来的那个文件（PDF 等），存在 `raw\` |
| **抽取** | 把 PDF/Word 里的文字提取成纯文本的过程 |
| **指纹** | 用算法给文件算出的唯一编号（SHA-256）。**内容相同指纹就相同**，用它查重，不看文件名 |

## 关于卡片

| 词 | 大白话解释 |
|---|---|
| **卡片** | 一页纸讲清一份资料的摘要，存在 `cards\` |
| **编号** | 每份资料的唯一标识，如 `2025-制度-0002`。**一经分配永不更改** |
| **front matter / YAML** | 卡片开头那一段被 `---` 夹住的字段区（属性区） |
| **字段** | YAML 里的一行，如 `年份: 2025` |
| **aliases（别名）** | 卡片的"小名"。有了它，`[[2025-制度-0002]]` 这种短链接才有效 |
| **标签** | 卡片的分类词，如「立项依据组织」。**只能从 `_schema\tags.md` 里选** |
| **可借鉴度** | 基金本子卡片的质量评级：高 / 中 / 低 |
| **存储模式** | `存档型` = 原件已复制进 raw；`引用型` = 原件留在原来的地方 |

## 关于 Obsidian

| 词 | 大白话解释 |
|---|---|
| **vault（仓库）** | Obsidian 里"打开的一个文件夹"。你的 vault 就是 `D:\KnowledgeBase` |
| **双链** | 卡片里的 `[[2025-制度-0002]]`，**能点的链接** |
| **反向链接** | 右侧面板，显示"哪些卡片提到了我" |
| **阅读视图 / 编辑视图** | `Ctrl + E` 切换。想看全字段用**编辑视图** |
| **排除的文件** | 搜索设置，让某些文件不参与搜索（建议排除 `md\` 和 `INDEX.md`） |

## 关于操作

| 词 | 大白话解释 |
|---|---|
| **收件箱** | `00_收件箱\`，新文件先放这 |
| **待归档** | 收件箱里等你处理的那一堆 |
| **已归档** | 归档完的原件挪到这里留档 |
| **归档** | 把新文件正式收进库的全过程（编号 → 建卡 → 更新索引） |
| **建卡** | 给一份资料写卡片 |
| **INDEX.md** | 各分类下的**总表** |
| **TAGS.md** | 各分类下的**标签索引** |
| **体检** | 让 AI 全面检查库有没有问题 |

## 关于 AI

| 词 | 大白话解释 |
|---|---|
| **agent** | 能干活的 AI，比如 harness / Codex / Claude Code / Kimi |
| **提示词** | 你复制给 AI 的一段话，存在 `_prompts\` |
| **批准** | AI 动手前给你的计划，你说"批准"它才做 |
| **审批框** | 系统弹的权限确认框，**点「允许」** |
| **只读操作** | 不改文件的操作（检索、统计），不用你批准 |

## 关于项目本子

| 词 | 大白话解释 |
|---|---|
| **本子** | 基金申请书的俗称 |
| **国自然 / NSFC** | 国家自然科学基金 |
| **青年 / 面上 / 重点 / 重大** | 项目类型。**青年**是给年轻科研人员的，也是你要申请的 |
| **申请代码** | 如 `F0610`。`F` 是信息科学部，`F02` 是计算机，`F06` 是人工智能 |
| **立项依据** | 本子里论证"为什么值得做这个研究"的那部分 |
| **科学问题** | 本子的核心，库里用四段式记：问题 / 为何是问题 / 难点 / 切入 |
| **创新点** | 本子里"我比别人新在哪"，库里用三段式记：针对 / 做法 / 效果 |
| **研究基础** | 本子里证明"我有能力做成"的部分（论文、专利、预实验） |
