# Obsidian 使用指南

> Obsidian 就是这个知识库的"看图软件"。**它不改动文件内容**，只是把 Markdown 显示得好看、能搜索、能点链接。

---

## 一、第一次打开：把知识库挂进去

1. 打开 Obsidian
2. 点 **「打开文件夹作为仓库」**（英文 *Open folder as vault*）
   - 如果之前建过别的仓库：点**左下角仓库图标** → 「打开另一个仓库」
3. 在文件选择框里定位到 **`D:\`** → 选中 **`KnowledgeBase`** 文件夹 → 点「选择文件夹」
4. 若弹出「信任作者并启用插件」，点它

完成后左侧会出现文件树。

---

## 二、界面认识

```
┌─────────────┬────────────────────────┬──────────┐
│  左侧        │      中间              │  右侧    │
│  文件树      │   卡片内容             │ 反向链接 │
│  （找文件）  │  （看内容 / 编辑）      │ 大纲     │
└─────────────┴────────────────────────┴──────────┘
```

- **左侧**：所有文件夹和文件。点分类 → 点 `cards` → 点卡片
- **中间**：卡片内容。**默认可能是"阅读视图"**（好看但字段折叠），
  想看清全部字段按 **`Ctrl + E`** 切到"编辑视图"（源码）
- **右侧**：可以打开「反向链接」面板，看**谁链接了当前这张卡片**

## 三、搜索（最常用的功能）

| 想干什么 | 按键 | 输入 |
|---|---|---|
| **搜全文内容** | `Ctrl + Shift + F` | `评价体系` |
| 快速跳转（模糊匹配文件名） | `Ctrl + O` | `评价` |
| 只在某个分类里搜 | `Ctrl + Shift + F` | `path:30_办公 评价体系` |
| 按标签搜 | `Ctrl + Shift + F` | `tag:#制度` |
| 排除原文干扰 | `Ctrl + Shift + F` | `评价体系 -path:md` |

**最直观的一招**：左侧文件树里**右键点分类文件夹** → 「**在文件夹中搜索**」。

### 强烈建议做一次设置（一劳永逸）

`Ctrl + Shift + F` 默认会连 `md\`（抽取的原文全文）和 `INDEX.md` 一起搜，结果多得看不过来。

**设置 → 文件与链接 → 排除的文件**，加入：

```
INDEX.md
TAGS.md
10_基金本子/md
20_教学/md
30_办公/md
45_论文/md
```

加完后搜索只走 `cards\`（卡片精华），结果就干净了。

## 四、卡片里的链接（双链）

卡片里会出现 `[[2024-制度-0003]]` 这样的东西——**这是能点的链接**，点一下跳到那张卡片。

**它的用途**：同一份文件有新旧版本时，两张卡片互相链接，你可以从新版一键跳回旧版查历史。

**注意两点**：

1. **只有正文里的链接能点**。最上面的属性区（灰底那一块）里的 `替代关系` 字段**不渲染成链接**
2. **如果点了没反应** → **完全退出 Obsidian 再打开**。
   因为 AI 在后台批量改了文件，Obsidian 没刷新。这不是库坏了

## 五、看原件（PDF / Word / PPT）

**最简单：卡片正文最上面有一行**

> 📎 [点这里打开原件（PDF）](../raw/2025-制度-0002.pdf)

**点它** → 直接用系统程序（PDF 阅读器 / Word / PPT）打开原件。

**注意**：能点的是**正文里**这一行。
最上面灰底的属性区里那个「源路径」显示的是同一份文件的路径，但那是给 AI 读的纯文本，**点不动**。

**其他办法**：

- 在 Obsidian 左侧展开对应的 `raw\` 文件夹，点那个文件
- 或者直接用文件资源管理器打开 `D:\KnowledgeBase\<分类>\raw\`

---

## 六、要不要改文件？

**建议不要**。原因：

- 卡片由 AI 维护，手改容易破坏格式（YAML 里的字段名、缩进很讲究）
- 索引是**从卡片自动重建**的，手改卡片会让索引对不上

**想改内容** → 告诉 AI 你想改什么，让它改，改完它会重建索引。

## 七、Obsidian 会在库里生成一个隐藏文件夹

`.obsidian\` —— 存界面配置用的。

- **正常现象，别删**
- 如果以后用网盘同步，**必须把 `.obsidian\workspace*` 排除掉**（每台电脑的窗口布局不同，同步会打架）。详见 `06_备份与迁移.md`
