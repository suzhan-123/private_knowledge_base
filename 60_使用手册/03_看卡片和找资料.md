# 看卡片和找资料

---

## 一、什么是"卡片"

库里每份资料都配一张**卡片**：一页纸讲清这份资料是什么、有什么价值。

**为什么不用直接看原文？**

| | 原文（`md\` 里的全文） | 卡片（`cards\` 里的） |
|---|---|---|
| 一篇基金本子 | 约 8000 字，读 20 分钟 | 约 400 字，读 1 分钟 |
| 一篇论文 | 约 5 万字 | 约 300 字 + 关键数据 |
| 用途 | 需要细节时才翻 | **平时看这个就够了** |

**三层结构，越往下越细**：

```
INDEX.md（总表：一眼看全部）
    ↓ 找到感兴趣的那条
cards\xxx.md（卡片：1 分钟了解）
    ↓ 确实需要细节
md\xxx.md（全文）  →  raw\xxx.pdf（原件）
```

## 二、五个分类，卡片看什么

### `10_基金本子` —— 中标本子（27 篇）

**最该看的两列**：

- **可借鉴度**：高／中／低。标「高」的是写法最好的
- **标签**：如「立项依据组织」「创新点表述」，按你要学的东西找

**卡片里最有用的两节**：

- **科学问题**（四段式：问题 / 为何是问题 / 难点 / 切入）
- **创新点**（每条：针对什么缺陷 / 怎么做 / 效果）

### `20_教学` —— 课件教案（2 份）

看「**知识点覆盖**」和「**可复用要点**」。后者写到了页码级，比如"第 15-18 页的讲法可以直接用"。

### `30_办公` —— 制度通知（6 份）

注意「**是否现行有效**」这一列：

- `是` = 现行版本
- `否` = 已被取代，**仅供回查历史**

### `45_论文` —— 学术论文（2 篇）

**这个分类专为"写本子找弹药"设计**，重点看：

- **一句话总结**（INDEX 第一列就能扫）
- **可引用论断**：能支撑你论证的观点
- **可放入本子的位置**：明确告诉你放哪一节
- **原文关键句**：英文原句 + 中译，**写本子时对照核对用**
- **局限性与可能的追问**：提前知道软肋

### `40_文献` —— 综述标准专利（暂空）

等你投喂材料。

## 三、怎么找

| 我想找 | 怎么做 |
|---|---|
| 某个方向的本子 | 打开 `10_基金本子\INDEX.md`，扫标题和标签 |
| 写法好的本子 | INDEX 按「可借鉴度 = 高」筛 |
| 只记得几个字 | Obsidian 按 `Ctrl + Shift + F` 搜全文 |
| 某个标签下的全部 | `Ctrl + Shift + F` 输 `tag:#立项依据组织` |
| 某个年份的 | INDEX 里看年份列 |
| 某个人的本子 | 搜姓名（卡片里有「申请人」字段） |
| 某个分类下的 | 左侧右键文件夹 → 「在文件夹中搜索」 |

**搜索排除设置**（避免结果太多）见 `02_Obsidian使用指南.md` 第三节。

## 四、注意：库里本子的年份

库里基金本子主要是 **2000–2012 年**的，最新两篇是 2020 和 2025。

**按库规则**：

> 年份距今超过 8 年的本子，**只能当"写法参照"，不能当"研究现状依据"**。

意思是：**结构怎么搭、科学问题怎么提炼、创新点怎么表述** —— 这些可以学；
但**具体的研究现状、别人做到什么程度** —— 必须你自己去查最新文献，不能引用老本子里的。
