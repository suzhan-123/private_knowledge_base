# 添加新文件

---

## 一、能收哪些格式

| 格式 | 能收吗 |
|---|---|
| PDF | ✅ |
| Word（`.doc` / `.docx`） | ✅ |
| PowerPoint（`.pptx`） | ✅ |
| Excel（`.xlsx`） | ✅ |
| 纯文本（`.txt` / `.md` / `.csv`） | ✅ |
| 网页（`.html`） | ✅ |
| 老的 `.ppt` / `.xls` | ⚠️ 先用 Office 另存为新格式 |
| 图片、扫描件 | ⚠️ 需要 OCR，暂时转人工 |

## 二、操作流程（三步）

### 第 1 步：丢文件

把文件**拖进**：

```
D:\KnowledgeBase\00_收件箱\待归档\
```

一次丢多少都行。

### 第 2 步：跟 AI 说一句话

打开任意一个 AI，说：

> **归档收件箱**

（库里已有现成提示词 `_prompts\02_批量归档.md`，它会照着做）

### 第 3 步：看计划，回一句"批准"

AI 会先给你一份计划（放哪个分类、编号是什么、有没有重复），**你看懂了就回「批准」**。

然后它会自动完成：复制原件 → 抽取文字 → 分配编号 → 建卡片 → 更新索引。

---

## 三、归档之后的文件去哪了

**跑完归档，`待归档\` 一定是空的** —— 原件会自动挪到：

| 情况 | 原件去向 | 含义 |
|---|---|---|
| 正常入库 | `00_收件箱\已归档\` | 留档备查，只增不删 |
| 和库里已有文件完全相同 | `00_收件箱\重复文件\` | 指纹撞车 |
| 抽不出来（加密/扫描件） | `00_收件箱\需人工确认\` | 等你人工看 |

**原件不会丢**，同时 `raw\` 里也有一份完整副本。

## 四、编号是怎么来的

每个分类有各自的编号格式：

| 分类 | 格式 | 例子 |
|---|---|---|
| 基金本子 | 年份-类型-学科代码-序号 | `2011-青年-F030602-0002` |
| 教学 | 年份-类型-序号 | `2026-课件-0001` |
| 办公 | 年份-类别-序号 | `2025-制度-0002` |
| 文献 | 年份-类型-序号 | `2024-标准-0001` |
| 论文 | 年份-第一作者姓-期刊简称-序号 | `2025-Hu-CVPR-0001` |

**编号一经分配永不更改** —— 改名会让所有引用断裂。

**年份抽不出来时**会写成 `XXXX`（不瞎猜）。如果你知道准确年份，告诉 AI 让它手工补。

## 五、重复文件怎么判断

用文件的**内容指纹**（SHA-256），不是看文件名。

所以：

- `期刊目录汇总.pdf` 和 `期刊目录汇总(2).pdf` 内容一样 → **会被认出来是重复**
- 即使改了名字，只要内容一样，也会被拦下
- **同一批文件之间的重复也能拦**（这个功能是后来补上的）

## 六、新旧版本怎么办

**同一份文件有多个版本时，每个版本都单独建卡**，而且两张卡片**互相链接**：

- 新版卡片里写着「取代 `[[旧版编号]]`」
- 旧版卡片里写着「被 `[[新版编号]]` 取代」
- 每张卡都有一节「**版本关系**」，写清哪个现行有效

**在 Obsidian 里点那个 `[[…]]` 就能从新版跳回旧版**（反过来也能跳）。

好处：制度年年修订，你既知道哪个是现行的，又能随时翻回旧版对比。

---

## 七、分类拿不准怎么办

**直接问 AI**，别自己猜。做法：

> 我往待归档放了几个文件，先别归档，告诉我它们各自该放哪个分类

**判断依据**：

| 内容 | 分类 |
|---|---|
| 基金申请书 / 标书 | `10_基金本子` |
| 课件、教案、试卷、实验指导 | `20_教学` |
| 制度、通知、表格、简历、考核标准 | `30_办公` |
| 学术论文（期刊/会议） | `45_论文` |
| 综述、标准、专利、教材、白皮书 | `40_文献` |
