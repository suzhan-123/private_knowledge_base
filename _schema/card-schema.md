# 卡片格式规范（schema_version: 1）

一张卡片 = 一篇本子的结构化摘要。**一篇一卡**，是 agent 检索时的主要读物。

## 字段定义

| 字段 | 必填 | 说明 |
|---|---|---|
| schema_version | 是 | 固定 1 |
| id | 是 | 编号，如 2011-青年-F030602-0001。一经分配永不更改 |
| 标题 | 是 | 项目名称。优先取原文「项目名称」，其次取文件名 |
| 项目类型 | 是 | 青年 / 面上 / 重点 / 重大 / 地区 / 其他 / 未提及 |
| 类型存疑 | 否 | 原文「资助类别」与「亚类说明」冲突时，把两者原文写在这里 |
| 学科代码 | 否 | 申请代码，如 F030602；原文没有则"未提及" |
| 年份 | 是 | 优先取「申请/申报日期」的年份（含中文数字年份）；推不出写"未提及" |
| 资助类别 | 否 | 原文原样，如"青年科学基金项目" |
| 申请代码 | 否 | 原文原样，如"F030602" |
| 申请人 | 否 | 原文原样（**仅本地保存，禁止外传**） |
| 依托单位 | 否 | 原文原样（**仅本地保存，禁止外传**） |
| 科学问题属性 | 否 | 原文若标注四类科学问题属性则照抄，否则"未提及" |
| 存储模式 | 是 | 存档型（原件已复制进 raw/）或 引用型（原件留在原处） |
| 源路径 | 引用型必填 | 原始文件完整路径；存档型可填素材来源 |
| 抽取质量 | 是 | 高 / 中 / 低（由 _tools/kb_extract.py 给出） |
| 篇幅 | 否 | 页数 / 正文约 N 字 / 图 N / 表 N / 参考文献 N |
| 结构 | 是 | 实际包含的章节列表 |
| 科学问题 | 是 | **四段式**：①问题（一句话点出要解决什么）②为何是问题（为什么非解决不可）③难点（卡在哪里）④切入（本课题从哪下手）。不抄原文 |
| 研究对象与边界 | 否 | |
| 创新点 | 是 | **每条三段式**：针对（什么问题/什么旧做法）-> 做法（具体怎么做）-> 效果（带来什么改进）。2-4 条 |
| 技术路线关键词 | 是 | 箭头串，如 数据构建 -> 特征刻画 -> 模型设计 -> 验证 |
| 研究基础亮点 | 否 | 论文/专利/预实验，数量级即可 |
| 写作特征 | 是 | 写法层面的观察：立项依据怎么收口、创新点怎么对应缺口 |
| 可复用要点 | 是 | 对写新本子有用的写法，2-5 条 |
| 可借鉴度 | 是 | 高 / 中 / 低，判据见 _schema/scoring.md |
| 标签 | 是 | 只能从 _schema/tags.md 选 |

## 硬要求
1. 每个字段要么有原文依据，要么写"未提及"。**禁止推测填空。**
2. 原文引用总计 <=50 字，只用于说明写法特征。
3. 年份早于当前年 8 年以上的，在"写作特征"末尾加时效提示。
