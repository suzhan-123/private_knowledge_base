# 命名与编号规范

## 文件命名
- 基金本子：{年份}-{项目类型}-{学科代码}-{四位序号}   例：2011-青年-F030602-0001
- 教学：{年份}-{类型}-{序号}
- 办公：{年份}-{类别}-{序号}
- 文献（综述/标准/专利/教材/报告）：{年份}-{类型}-{序号}
- 论文（学术论文）：{年份}-{第一作者姓}-{期刊简称}-{序号}

## 卡片文件名（2026-09-11 起）
- 格式：`{编号} {短标题}.md`，例 `2025-制度-0002 大连理工大学专任教师学术贡献评价体系（2025年4月修订）.md`
- 短标题超过 40 字截断并加 `…`；去掉 Windows 非法字符 `\ / : * ? " < > |`
- **每张卡片 YAML 必须写 `aliases:` 含编号**，否则 Obsidian 里 `[[编号]]` 双链会断
- `raw/` 与 `md/` 下的文件名**只保留编号、不加标题** —— 卡片里的「源路径」依赖它们
- **为什么这么设计**：文件名要能被人一眼看懂（文件树里 `2024-制度-0006` 是啥根本认不出），
  但双链又依赖文件名，所以用 aliases 把编号保住，两头都不丢

## 编号规则
1. 序号在**分类内**连续分配，从 0001 开始。
2. **编号一经分配永不更改**——改名会让所有引用断裂。
3. 引用一律用编号，不用文件名。
4. 分配前先扫该分类 INDEX.md 里已有的最大序号，+1 使用。
5. 类型或学科缺失时用 `XX` 占位（如 `2005-面上-XX-0003`），**不要瞎猜**。
6. 去重命中的文件不分配编号，移入 00_收件箱\重复文件\。

## 素材区文件不改名
档案区（D:\KnowledgeBase）内按上面规则重命名；
**素材来源区的原始文件名一律不动**，只读取、只复制。
